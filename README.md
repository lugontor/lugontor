# 🚀 Proyectos destacados

## 🔐 Implementación y análisis de MACsec

### Trabajo de Fin de Grado – Ingeniería Informática

Proyecto centrado en el estudio, implementación y análisis de **MACsec (IEEE 802.1AE)** como mecanismo de seguridad para comunicaciones Ethernet de nivel 2.

### 🔎 Áreas trabajadas

- IEEE 802.1AE
- Ethernet IEEE 802.3
- Seguridad de capa 2
- MACsec
- SecY
- SecTAG
- AES-GCM
- GCM-AES-128 / 256
- Protección frente a ataques de repetición
- Packet Number (PN)
- Ventanas Anti-Replay
- ARP
- IP sobre Ethernet

### 🧪 Entorno de pruebas

El proyecto incluyó la creación de un entorno experimental para analizar el funcionamiento de MACsec y su impacto sobre las comunicaciones.

Entre las pruebas realizadas:

- Configuración de nodos MACsec
- Captura y análisis de tráfico
- Análisis de tramas Ethernet
- Pruebas de conectividad
- Pruebas Anti-Replay
- Análisis del Packet Number
- Pruebas de rendimiento
- Comparación de comunicaciones protegidas y no protegidas

### 🛠️ Herramientas

`Linux` `MACsec` `Wireshark` `iproute2` `iperf3` `ping` `Bash`

## 🤖 Sistema Multiagente – Warehouse

Proyecto desarrollado utilizando **JaCaMo y Jason** para la implementación de un sistema inteligente basado en agentes aplicado a la gestión autónoma de un almacén.

El sistema permite que diferentes agentes colaboren para gestionar tareas y tomar decisiones de manera autónoma.

### Características

- Arquitectura multiagente
- Agentes BDI
- Gestión autónoma de tareas
- Navegación dinámica
- Búsqueda Best-First
- Heurística Manhattan
- Gestión de tráfico
- Priorización mediante deadlines
- Gestión de zonas
- Reservas de recursos
- Comunicación entre agentes
- Gestión de fallos

### 🛠️ Tecnologías

`Java` `Jason` `JaCaMo` `BDI` `Multi-Agent Systems` `Artificial Intelligence`
